## Recomendación de estudio

1. Empieza por conceptos básicos: variables, tipos y operadores.
2. Luego revisa control de flujo y funciones.
3. Después avanza a POO y manejo de errores.
4. Usa los ejemplos como referencia práctica.
5. Cuando veas un error con código `NXxx`, busca su solución en el [catálogo de errores](language/errors/errors.md).

> La estructura está pensada para facilitar la lectura y mantener un orden lógico del curso.
