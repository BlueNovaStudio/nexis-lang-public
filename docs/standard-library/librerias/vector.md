# Librería Vector en Nexis

Proporciona el arreglo dinámico `Vector<T>`.

## Importación

```
#inject vector;
```

## Declaración

```
Vector<int> puntajes = []
Vector<string> nombres = ["Ana", "Carlos", "Luis"]
```

## Operaciones principales

- `agregar(valor)` añade al final.
- `insertar(indice, valor)` inserta en una posición.
- `obtener(indice)` y `asignar(indice, valor)` acceden o modifican un elemento.
- `eliminar(indice)` y `extraer()` eliminan elementos.
- `contiene(valor)`, `ordenar()`, `invertir()` y `longitud()` consultan o transforman el vector.

Consulta [la documentación completa de Vector](../collections/vector.md).
