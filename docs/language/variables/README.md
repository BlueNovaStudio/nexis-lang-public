# 📘 Variables, entrada y salida en Nexis

Esta sección explica cómo crear variables, mostrar información en pantalla y leer datos desde el usuario.

## Contenido

- [Declaración e inicialización](declaration.md)
- [Impresión y lectura](input-output.md)

---

## Temas que verás

### Variables

Las variables permiten guardar información en memoria para usarla más adelante.

### Entrada

La entrada permite recibir datos del usuario o de otro origen.

### Salida

La salida permite imprimir mensajes, resultados o cualquier valor útil.

---

## Flujo recomendado

1. Aprende a declarar e inicializar variables.
2. Luego practica la impresión de mensajes.
3. Después trabaja con lectura de datos desde teclado.

Esto te ayuda a construir programas simples con una base sólida.
