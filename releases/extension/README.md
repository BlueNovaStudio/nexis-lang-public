# ⏳ Extension

Componente **extension** del proyecto Nexis: la **extensión de Visual Studio Code** (resaltado de sintaxis, snippets, icono y documentación embebida).

Versiones publicadas:

- [v0.0.1](v0.0.1/README.md) — Release inicial: soporte base de sintaxis (`source.nexis`), comentarios y registro `.nxs`.
- [v0.0.2](v0.0.2/README.md) — Actualización: gramática realineada con la documentación del lenguaje, `fs"…"`, `#inject`, 20 snippets e icono propio.

> El código fuente de la extensión se mantiene en el repositorio privado de desarrollo de Nexis (nexis-lang).
