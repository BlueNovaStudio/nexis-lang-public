# Extension v0.0.1 — Release inicial

**Componente:** extension · **Fecha:** 2026-09-05 · **Tipo:** Release inicial

Primera versión de la extensión **Nexis Language Support by BlueNova** para Visual Studio Code.

## Qué incluye esta versión

- Resaltado de sintaxis del lenguaje Nexis (gramática TextMate `source.nexis`).
- Soporte de comentarios y configuración del lenguaje para VS Code.
- Registro de archivos con extensión `.nxs`.
- Categorías y metadatos publicados por `bluenovastudio`.
- Paquete `.vsix` listo para instalar.

## Cambios respecto a la anterior

- Primera release del componente; no existe versión anterior.

## Artefactos

- [nexis-programming-language-support-0.0.1.vsix](nexis-programming-language-support-0.0.1.vsix)

> El código fuente de la extensión se mantiene en el repositorio privado de desarrollo de Nexis (nexis-lang).
